Content-Type Converter
======================

Content-Type Converter is a Burp Suite extension for quickly rewriting request
bodies between JSON, XML, and `application/x-www-form-urlencoded`. It also adds
a POST-to-GET conversion action that moves request parameters into the query
string.

The extension is intended for editable request views such as Repeater, Intruder,
and Proxy intercept request editors.

Features
--------

- Convert request body to XML.
- Convert request body to JSON.
- Convert request body to `application/x-www-form-urlencoded`.
- Convert POST requests to GET requests while preserving parameters.
- Convert GET parameters to POST body formats through the existing XML/JSON
  conversion actions.

Build
-----

Requirements:

- Java 8 or newer.
- Maven.

Build the Burp-loadable jar:

```sh
mvn clean package
```

Load this file in Burp Extender:

```text
target/ContentTypeConverter.jar
```

Usage
-----

1. Open or intercept a request in Burp.
2. Right-click inside an editable request message editor.
3. Select one of the extension actions:

```text
Convert to XML
Convert to JSON
Convert to x-www-form-urlencoded
Convert POST to GET
```

Conversion behavior
-------------------

### JSON to XML

Input:

```json
{
  "product_url": "https://example.com/products/123",
  "title": "demo product",
  "plan": "false"
}
```

Output:

```xml
<?xml version="1.0" encoding="UTF-8" standalone="no"?>
<root>
    <product_url>https://example.com/products/123</product_url>
    <title>demo product</title>
    <plan>false</plan>
</root>
```

### XML to JSON

When XML contains a top-level `<root>` element generated by this extension, the
wrapper is removed when converting back to JSON.

Input:

```xml
<?xml version="1.0" encoding="UTF-8" standalone="no"?>
<root>
    <product_url>https://example.com/products/123</product_url>
    <title>demo product</title>
    <plan>false</plan>
</root>
```

Output:

```json
{
  "product_url": "https://example.com/products/123",
  "title": "demo product",
  "plan": "false"
}
```

XML text values are kept as strings. For example, `<plan>false</plan>` becomes
`"plan": "false"` instead of `"plan": false`.

### Any Body to x-www-form-urlencoded

The `Convert to x-www-form-urlencoded` action uses a best-effort parser:

- JSON objects are flattened into key/value pairs.
- XML is converted through JSON-style keys.
- Existing form bodies are normalized.
- Multipart or unknown bodies use parameters parsed by Burp when available.
- Raw bodies that cannot be parsed are emitted as `value=<body>`.

Nested values use bracket notation before URL encoding:

```json
{
  "user": {
    "name": "alice"
  }
}
```

```text
user%5Bname%5D=alice
```

### POST to GET

The `Convert POST to GET` action first normalizes the request body to
`application/x-www-form-urlencoded`, then uses Burp's request method conversion
helper to move body parameters into the URL query string.

This preserves parameter names and values more reliably than manually editing
the request line.

Notes
-----

- Only the first selected request is modified.
- Cookies are not copied into form bodies.
- `Content-Type` is replaced with the target format when a body conversion is
  performed.
